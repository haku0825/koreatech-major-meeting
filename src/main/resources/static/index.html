매칭보드 쪽지함 회원가입 계정

한기대 과팅 매칭 서비스

회원가입/인증 후 매칭 글을 올리고, 쪽지함에서 대화를 시작하세요. 기능은 페이지별로 분리되어 있고, 필요한 작업만 각 페이지에서 수행하도록 구성했습니다.

내 정보: -

사용 방법

  1. `회원가입` 페이지에서 가입 후, `계정` 페이지에서 이메일 인증/학생증 인증을 진행합니다.
  2. `매칭보드` 페이지에서 모집글을 작성하거나, 다른 모집글에 쪽지를 보냅니다.
  3. `쪽지함` 페이지에서 내 채팅방 목록을 보고, 원하는 방을 눌러 대화로 이동합니다.
  4. 채팅은 `채팅방` 전용 페이지에서만 진행됩니다.

문의 / 문제 신고

서비스 사용 중 문제 있으면 인스타그램 srsxb10_ 으로 연락 주세요.

가능하면 문제 화면 캡처와 재현 순서를 같이 보내주면 더 빠르게 처리할 수 있습니다.
